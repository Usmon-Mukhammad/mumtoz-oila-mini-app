# Mumtoz Oila — Mini App (static)

Static deploy of the Telegram Mini App UI kit from the [Mumtoz Oila design system](../Mumtoz-Oila): journey-map home, chapter/lesson audio player, Sinov quiz, and quiz results.

No build step — plain HTML/CSS/JS with in-browser JSX (Babel standalone) via CDN. Open `index.html` directly or serve the folder statically.

Deployed via GitHub Pages, fronted by `mumtoz-oila.tavfiqnashr.uz`.
